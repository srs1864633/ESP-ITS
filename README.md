# ESP-ITS
This repository accompanies the proposed processing framework for LiDAR point clouds in dense forests, which consists of three sequential stages implemented by three methods:

ESP-ITS: exhaustive stem-point individual tree segmentation

SMP-NGS: SMP-based near-ground noise point separation

SGBE-LWS: skeleton-guided branch expansion for leaf–wood separation

The full code for all three methods will be made open-source upon acceptance of the manuscript.
